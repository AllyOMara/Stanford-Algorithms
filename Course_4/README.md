# Course 4

## Overview
Course 4 of Algorithms Specialization. Shortest Paths Revisited, NP-Complete Problems and What To Do About Them.<br><br>

## Solutions
### [Week 1 - Shortest Shortest Path](https://github.com/AllyOMara/Stanford-Algorithms/blob/main/Course_4/Week_1/Week_1_Assignment.py)
Computes and prints the "shortest shortest path".<br>
Specifically, identify which graph have no negative cycles, and then compute all-pairs shortest paths, remembering the shortest one.<br>
Uses the Floyd-Warshall algorithm.<br>
#### Key Implementations
- 3-Dimensional array - using create_shortest_paths_array, creates a 3-dimensional array.
- Pytest usage - uses one file (Assignment_1_Test.py) to test 5 different cases.
- Shell script usage (Linux) - automated testing and running of the program

### [Week 3 - Travelling Salesman Problem Heuristic](https://github.com/AllyOMara/Stanford-Algorithms/blob/main/Course_4/Week_3/Week_3_Assignment.py)<br>
Uses a heuristic to generate a solution to the Travelling Salesman Problem (TSP).<br>
Finds and prints the overall cost (distance) of the TSP tour found using the heuristic.<br>
#### Key Implementations
- Heuristic - non-accurate fast algorithm designed to be able to handle large files.<br>
- Shell script usage (Linux) - automated testing and running of the program..<br>
